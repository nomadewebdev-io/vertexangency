# Vertex Agency - Landing Page

Landing page moderne, réactive et performante pour l'agence digitale **Vertex Agency**.

## 🚀 Fonctionnalités & Sections
- **Header / Navigation** : Menu responsive avec drawer animé sur mobile, effet sticky blur au scroll et liens d'ancrage fluides.
- **Hero Section** : Accroche percutante *"Sites web professionnels sur mesure"*, CTA interactifs, badges technologiques et compteurs animés de statistiques.
- **Nos Services** : 5 cartes de services avec visuels immersifs, micro-interactions et effets de survol.
- **Nos Réalisations** : Filtres interactifs par catégorie et fenêtre modale dynamique détaillée pour chaque projet.
- **Témoignages Clients** : 6 avis clients avec notations 5 étoiles et visuels soignés.
- **Contact & Devis** : Formulaire de contact fonctionnel avec validation en temps réel, retour utilisateur toast et célébration interactive.
- **Footer** : Liens de navigation, services et mentions légales.

## 🛠️ Technologies
- **HTML5 Sémantique** & SEO optimisé
- **Vanilla CSS** (Design System sur mesure, DIN Pro typography, Glassmorphism, animations fluides)
- **Vanilla JavaScript ES6+** pour toutes les interactions
